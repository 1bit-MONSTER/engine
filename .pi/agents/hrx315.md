## The four traps — a count is not a verdict

Four readings have been lost in one session to a single shape: **a count read as a verdict, without checking
the count can be non-zero for the reason the verdict assumes.** Every corrupted verdict pointed at a pass not
earned or a fault that did not happen. Assume any harness you are shown has these until you check it:

1. **A skip is not a pass.** The eight `test-hrx-*` binaries **exit 0** while printing `no HRX0 device, skipped`
   unless `LD_LIBRARY_PATH` and `IREE_HAL_AMDGPU_LIBHSA_PATH` are set. Count `skip` separately, always.
2. **`grep -c … || echo 0` yields `"0\n0"`** — `grep -c` prints `0` *and* exits 1, so the fallback also runs;
   `[ "$N" -eq 0 ]` then errors to the *else* branch. This made a clean run print `FAULT or incomplete`.
3. **Count occurrences, not lines.** `/v1/chat/completions` responses are concatenated without newlines, so
   `grep -c '"content"'` reads 50 responses as **1**. Use `grep -o … | wc -l`.
4. **`pgrep -f "<pattern>"` matches your own monitoring one-liner**, so a wait-loop for "nothing running" never
   fires. Read `/proc/<pid>/cmdline` and skip `bash -c` wrappers. A CI watcher with this flaw printed GREEN on a
   branch whose checks had not started.

## Box and build facts that are easy to get wrong

* Build identification: `~/wt/315logwait-build` is the **current** build (source pin **`47a8fe929`**, eight
  `test-hrx-*` binaries); `~/wt/315fp-build` and `~/wt/315probe-build` are **old-pin** (`e44c9d01a`); a result
  measured on an old pin **does not describe what ships**.
* `BUILD_TESTING=ON` alone does **not** build the tests — the real gate is `-DLLAMA_BUILD_TESTS=ON`.
* Fingerprint selectors: **`EXTRA_ENV` splits on commas**, so only the first name survives; use
  `tail:<N>` / `head:<N>` for several. `tail:16` covers `attn_norm-*` but **not** the `ffn_moe_*` family.
* A name selector that matches **nothing** looks exactly like "zero NaN". The census has 946 distinct node
  names and contains **none** of `ffn_moe_probs-*`, `ffn_moe_topk-*`, `ffn_moe_argsort-*`, `ffn_moe_weights-*`.
  Confirm your selector matched **before** reading its zeros.
* Take the box lock (`flock` on `~/.cache/lax-decode/box.lock`) and leave the box clean: lock free, no owned
  servers, no forcer processes.
